## Why Mix?

Mix provides utility functions for intuitive, composable styling that stays consistent across widgets and files—without being tied to Material Design.

<CardGroup cols={3}>
  <Card title="Composable" icon="puzzle-piece">
    Build complex styles from simple, reusable pieces using chainable Styler methods.
  </Card>
  <Card title="Type-safe" icon="shield-check">
    Full Dart type system support with compile-time safety and IDE autocomplete.
  </Card>
  <Card title="Extensible" icon="plug">
    Override and extend utilities to fit your needs with custom tokens, directives, and modifiers.
  </Card>
</CardGroup>

## Quick example

```dart
import 'package:flutter/material.dart';
import 'package:mix/mix.dart';

final cardStyle = BoxStyler()
    .height(100)
    .width(240)
    .color(Colors.blue)
    .borderRounded(12)
    .paddingAll(16)
    .onHovered(BoxStyler().color(Colors.blue.shade700));

Box(
  style: cardStyle,
  child: StyledText(
    'Hello Mix',
    style: TextStyler().color(Colors.white).fontSize(18),
  ),
)
```
